# 4. DESIGN SYSTEM

## 4.1 Color palette

Use these exact primary colors:

| Color | Hex | Usage |
|---|---|---|
| Deep Forest Green | #182B29 | Header, dark sections, footer |
| Champagne Gold | #C4A574 | Buttons, highlights, icons |
| Warm Ivory | #F6F4EF | Main background |
| Charcoal | #343A40 | Body text |
| White | #FFFFFF | Cards and light surfaces |

Supporting colors may include:

- Dark Forest: #092521
- Muted Gold: #AD8C58
- Light Gold: #E9D8B9
- Soft Gray: #777B78
- Light Border: #E7E2D8

Use gradients only where needed for hero image readability or subtle visual depth.

Avoid bright colors, neon accents, exaggerated shadows, and excessive glassmorphism.

## 4.2 Typography

Headings: Playfair Display

Body: Inter

Suggested desktop typography:

- Hero heading: 64–76px
- Main section heading: 42–52px
- Card heading: 22–26px
- Body text: 16–18px
- Eyebrow labels: 11–13px, uppercase, letter-spaced

Use responsive font sizes with CSS clamp() where appropriate.

Headings should feel elegant, editorial, and architectural.

## 4.3 Layout

Maximum content width: 1280px

Use consistent horizontal padding.

Desktop section spacing: approximately 96–120px, adjusted to match the reference.

Tablet spacing: approximately 64–80px.

Mobile spacing: approximately 48–64px.

Use CSS Grid and Flexbox.

Avoid excessive rounded corners.

Cards should have subtle borders, refined shadows, and elegant hover interactions.

## 4.4 Buttons

Primary button:
- Champagne gold background.
- Dark text.
- Small border radius.
- Arrow icon where appropriate.
- Elegant hover transition.

Secondary button:
- Transparent background.
- Contrasting border.
- Light text on dark sections.
- Subtle hover treatment.

Buttons must be keyboard accessible.

## 4.5 Animations

Use subtle animations only:

- Fade-in on scroll.
- Gentle upward reveal.
- Image zoom on hover.
- Smooth button transitions.
- Underline animations on navigation.
- Optional subtle hero motion.

Do not use excessive parallax or dramatic motion effects.

Respect prefers-reduced-motion.
